> 加密者的线索策略与守则，由 prompts 包解析：# 开头是分节，- 开头是一条，> 是给人看的注释。
> 核心原则与红线整段进入每次加密请求；绿色、黄色策略由 AIPlayer 轮换取用（黄色每第三次抽中一条）；人类专用一节不参与轮换。

# 核心原则
1. 队友能解 > 对手难查表 > 污染对手笔记 > 拦截对手。
2. 黑标惩罚极重；任何情况下，先保证队友不猜错，再考虑让对手猜错。
3. 线索必须与目标词有明确意义关联。
4. 优先使用绿色策略；黄色策略仅在确认队友能解、不触红线时使用。
5. 不直接说出完整关键词，不泄露密码卡数字，不使用私人暗号。

# 绿色策略（优先使用）
- 二次联想：先指中间物，再让队友跳到目标词。例：长城→孟姜女；火锅→毛肚。
- 多层抽象：多跳一层，或给熟语半截。例：汉堡→疯狂；火锅→码头。
- 场景实物：用具体动作、场合、实物侧写。例：玻璃→镜子；火锅→九宫格。
- 借形换靶：模仿旧线索形式，实际指向别词。例：旧“重庆→火锅”，本轮“潍坊→风筝”。
- 公共典故：用成语、传说、歌词、民俗、行话。例：长城→好汉；风筝→断线。
- 熟语半截：给常用搭配的一半。例：火锅→底料；风筝→掌子。
- 动词化：用只有目标词接得住的动词。例：风筝→放；长城→登。
- 时序节令：用季节、节令、朝代、时辰。例：风筝→三月；火锅→数九。
- 上下位替换：用上位词或下位词。例：长城→关隘；火锅→炊具。
- 部件/配件：给组成部分或配件。例：长城→烽火台；火锅→鸳鸯。
- 功能后果：说用途或后果。例：玻璃→挡风；火锅→驱寒。
- 并列搭档：给常并列、对仗、组合的词。例：长城→运河；玻璃→陶瓷。
- 角色代言：给强关联人物或职业。例：长城→戍卒；玻璃→吹工。
- 文化坐标：用朝代、地域、流派。例：长城→秦；火锅→川。
- 流程步骤：给制作或使用步骤。例：风筝→扎骨架；玻璃→吹。
- 空间关系：给常出现的位置。例：长城→山脊；风筝→天上。
- 公共作品：用公共歌曲、电影、诗句。例：风筝→追风筝的人。
- 排列干扰：与本轮已给的线索保持同一种风格（都偏空间、或都偏时序），让对方难以靠风格差异给你队的联想建模。
- 笔记反制：历史记录里有对方每次的拦截猜测，那就是他们的笔记——找出他们把你队的哪类线索归到了哪个编号，然后给出符合这个规律、实际指向别处的线索。

# 黄色策略（谨慎使用）
- 反义侧写：说反面或缺失。例：火锅→冰块；玻璃→塑料。
- 拟声：用目标物声音。例：火锅→咕嘟；玻璃→吱嘎。
- 多义错位：利用多义词指向另一义项。例：长城→防火墙；玻璃→心（玻璃心）。
- 量词/单位：用独特量词。例：长城→一道；玻璃→一扇。
- 否定限定：说“不是什么”再加范围。例：玻璃→不是塑料；火锅→不是冷盘。
- 情绪标签：给典型情绪。例：长城→自豪；火锅→热闹。
- 缺失后果：说坏了会怎样。例：玻璃→漏风；风筝→栽头。

# 红线（禁止）
- 直接说出完整关键词。
- 提示字数、位置、发音、谐音、拼音、书写方式、偏旁、笔画、结构、字母。
- 直接外语翻译。
- 内部梗、私人约定、只有特定人懂的暗号。
- 只和关键词中某个字相关。
- 线索与目标词无意义关联。
- 使用符号、图形、表情代替词语，除非村规明确允许。

# 人类专用（不参与轮换）
> 以下依赖语音讨论、跨局记忆、队内默契或三条线索的统筹，单次线索请求执行不了，留作人类玩家备忘。
- 第四词烟雾：让线索表面像指向本轮未用到的第四词，靠队友对加密者的信任排除——AI 队友没有这层信任推理，会直接猜那个词，吃黑标。
- 假表养殖：前几轮固定某词某类线索，关键轮换给别词，诱导对手查错表——需要跨回合的蓄意重复，与“每次换联想角度”冲突。
- 讨论噪音：对方加密者旁听时，故意讨论错误方向，关键推理留到最后。
- 圈子作品梗：仅限队内都懂、且不违反明文规则时使用。
- 合法联想库：队内约定“产地、典故、动作、部件”轮换，但避免私人约定。
- 轮换风格：避免固定加密风格，让对手难建模（AI 侧已由策略轮换实现）。
- 赛后复盘：记录每轮线索、密码、对手猜测，更新对手推理模型。
