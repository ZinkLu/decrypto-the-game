# Console 主题色

四套主题沿用同一暖象牙白外壳、纸张、金属件、朱红实体按钮和绿色示波器。配色定义在 `web/src/components/console/model.ts`；色值是参考经典 Decrypto 视觉重新设计的 sRGB 色板，不是官方发布的品牌色。

## 队伍身份

| 主题 | ID | 己方印刷 / 屏幕 | 对方印刷 / 屏幕 |
|---|---|---|---|
| 原版黑白红（默认） | `classic` | `#383B36` / `#E9DFC7` | `#2C3539` / `#AFC2CC` |
| 蓝调电台 | `radio` | `#365D70` / `#A4C7D8` | `#8A4436` / `#E4AE99` |
| 琥珀档案 | `amber` | `#7A542B` / `#E5C28B` | `#315F62` / `#A0CAC7` |
| 紫棕密令 | `violet` | `#674E64` / `#CDB6CD` | `#586244` / `#BCC99C` |

`ink` 用于浅色纸张和移动端，`light` 用于暗屏。实体队牌使用独立的 `plate` / `onPlate`：原版己方为 `#EFE5CF` 白牌、`#383B36` 深字与描边；其他牌面使用对应印刷色作底、`#F2E8D3` 暖白字。队伍映射仍随玩家身份改变，A/B、己方/对方文字一直保留。

原 `rose` 偏好迁移为 `radio`；其余已有 ID 保留。未知或不可读取的偏好回退到 `classic`。

## LED 点阵

词窗使用独立于双方身份色的第三种「设备色」。同一主题下，A、B 两队共用词窗配色；队牌及主屏行动提示仍按我方 / 对方区分。设备色不复用任意一方的光色，避免暗示词窗属于某个队伍。

| 主题 | 关键词发光色 | 编号与说明发光色 |
|---|---|---|
| 原版黑白红 | `#F1B09D` 珊瑚红 | `#D7CFB8` 暖白 |
| 蓝调电台 | `#E3CF86` 香槟黄 | `#D7CFB8` 暖白 |
| 琥珀档案 | `#CBBAED` 薰衣草紫 | `#D7CFB8` 暖白 |
| 紫棕密令 | `#9BCEEC` 冰蓝 | `#D7CFB8` 暖白 |

三套新增设备光色按 OKLCH 选取后转换为 sRGB，以适配 Canvas 与 Three.js：蓝调为 `oklch(85.5% .095 95)`，琥珀为 `oklch(82% .072 300)`，紫棕为 `oklch(82.5% .068 235)`。暖黄补充蓝 / 砖红，淡紫补充琥珀 / 青绿，冰蓝补充灰紫 / 橄榄；原版继续用珊瑚红补充黑白。

保留近黑底板，不引入整块主题背景。离线信息复用暖白灯珠并显示明确文字，不增加第三种发光色。纹理中的 RGB 是语义通道，不是最终颜色。四块模块共用原有换色总线：全部熄灭后再交换配色、依次启动；隐私撤销始终立即替换内容。

| 主题 | 暗底 | 字色 | 内沿 / 网格基色 |
|---|---|---|---|
| 原版黑白红 | `#4A1612` | `#F1B09D` | `#8E493A` |
| 蓝调电台 | `#292411` | `#E3CF86` | `#6C6342` |

| 紫棕密令 | `#142731` | `#9BCEEC` | `#47687C` |

字色、塌缩亮线、余辉及暗部染色随同一个画面快照交换，避免蓝色主题在关机时又闪回红色。四支管保留各自的启动公差与扫描效果。主题切换先熄灭旧画面，再显示新配色；LED/CRT 试装沿用原有开发预览入口 `?words=led` / `?words=crt`。

## 协调性与验证

- 通用设备字色为印刷 `#595A4E` / 暗屏 `#D7CFB8`；警告为印刷 `#8A4C23` / 暗屏 `#EDBC80`。游戏结果信号和固定硬件色保持独立于主题。
- 自动检查覆盖浅底印刷、队牌文字、主屏文字、CRT 文字及两种 LED 光色的实色对比度，最低要求为 4.5:1。机壳平面对照使用 `#E6DEC9`；这不等同于实际 3D 材质所有光照下的对比度认证。
- 验证主题迁移、双方身份映射、中英文词窗、私密信息隐藏，以及白队牌的深字。整机显示仍需通过浏览器检查灯光、玻璃反射和点阵显示。
- LED / CRT 共用材质保留两套实时参数，避免返回缓存着色器时沿用旧颜色。浏览器已检查四套主题的整机或词窗细节，并复测硬件来回切换后的配色。
