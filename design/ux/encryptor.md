# Encryptor — 加密者输入线索

> 页面组件: `Encryptor.tsx`
> 游戏阶段: `encrypting`
> 角色: `encryptor`（当前轮次的加密者）

## 页面用途

加密者收到 3 个密码序号，需要为每个序号对应的词给出 1 条线索。这是加密阶段的核心交互。

## 页面信息

- **倒计时** — 90 秒限时，带进度条
- **进度指示器** — 显示 3 张卡片的完成状态（✓ / 当前 / 待填）
- **当前卡片** — 显示：
  - 密码序号（1-4 中的一个）
  - 对应的密码词
  - 线索输入框
- **左右预览** — 桌面端可看到相邻卡片编号（移动端点击两侧切换）
- **紧急提示** — 剩余时间不足时出现 URGENT 标记
- **历史记录** — 可展开查看过往轮次的线索-密码对照

## 用户操作

1. **输入线索** — 在输入框中为当前卡片输入线索词（最长 8 字符，过滤特殊字符）
2. **切换卡片** — 点击左右预览区域或进度指示器切换到其他卡片
3. **查看历史** — 点击按钮展开历史抽屉，查看过往轮次记录
4. **提交线索** — 在第 3 张卡片填写完成后，出现「DISPATCH INTEL」按钮，点击提交全部 3 条线索

## 用户流程

```
看到卡片 1（密码序号 + 密码词）
→ 输入线索 → 切换到卡片 2
→ 输入线索 → 切换到卡片 3
→ 输入线索 → 出现提交按钮
→ 提交
```

## 状态流转

- 前置: `phase_change` 消息中 `phase=encrypting` 且 `your_role=encryptor`
- 后续: 提交后进入解密阶段，本人转为 **EncryptorWatching（加密者观战）**
- 超时: 未在限时内提交的处理由服务端决定

## Store 交互

- 读取: `secretDigits`, `secretWords`, `myWords`, `history`
- 写入: `submitClues(clues[3])`
