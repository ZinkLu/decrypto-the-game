# Opponent Intercepting — 对手拦截

> 页面组件: `OpponentIntercepting.tsx`
> 游戏阶段: `intercept`
> 角色: `opponent`（对方队伍）

## 页面用途

对手队伍发起拦截后，在此猜测对方的密码序列。交互方式与队友解码类似，但时间更短（45 秒）且使用敌方主题。

## 页面信息

- **倒计时** — 45 秒限时（比解码阶段短）
- **标题** — 「INTERCEPT OPERATION」
- **当前线索** — 本轮的 3 条线索词（只读展示）
- **情报摘要** — 可折叠的历史情报面板：
  - 默认收起，点击展开
  - 显示历史轮次的线索和已知序列
  - 简化版（无点击高亮功能）
- **拦截输入行** — 3 行（每条线索一行），每行包含：
  - 线索内容
  - 答案输入格
  - 状态指示
- **数字键盘** — 1-4 四个按钮（敌方配色）

## 用户操作

1. **展开/收起情报摘要** — 点击切换历史情报面板的展开状态
2. **点击输入格** — 激活某一行的输入
3. **点击数字键** — 将 1-4 填入当前激活的输入格
   - 填入后自动跳到下一个空格
   - 键盘数字键 1-4 同样有效
4. **清除答案** — 点击已填写的输入格可清空
5. **确认拦截** — 3 格全部填满后出现「确认拦截」按钮，点击提交

## 用户流程

```
查看 3 条线索 + 展开历史情报（可选）
→ 点击输入格 1 → 选择数字
→ 自动跳到输入格 2 → 选择数字
→ 自动跳到输入格 3 → 选择数字
→ 出现确认按钮 → 点击提交
→ 显示「拦截指令已发送…」等待结果
```

## 状态流转

- 前置: `phase_change` 消息中 `phase=intercept` 且 `your_role=opponent`
- 后续: 拦截判定完成后进入 **RoundResult（回合结算）**

## Store 交互

- 读取: `clues`, `history`
- 写入: `submitIntercept(guess[3])`
