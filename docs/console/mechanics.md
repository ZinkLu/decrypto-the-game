# 机械与交互

这份文档说明 Console 上每一个会动、可操作的部件：它在游戏里的职责、怎么操作、动作的时序，以及对应的源码。屏幕上画什么见[显示器件](displays.md)，声音见[声音](audio.md)，背面的供电与接线见[背面联动](rear-linkage.md)，代码的整体组织见[代码组织](code.md)。

源码都在 `web/src/console/`。文中的长度以模型单位计，时间以毫秒计，数值取自代码中的常量。

## 操作总则

**所有控件都是真实的 DOM 元素。** `paint()` 在绘制各个表面的同时登记交互目标（`Target`），`Controls.tsx` 为每个目标渲染一个透明的 `<button>`、`<input>` 或 `<a>`，`engine.ts` 的 `bounds()` 按当前相机把它投影到模型上对应的位置。因此每个控件都能用 Tab 聚焦、用 Enter 或 Space 触发，并带有随状态变化的 `aria-label`；旋钮是 `role="slider"`，电源、AUTO/MAN、音乐和音效开关是 `role="switch"`。

**只有一个确认动作。** 红色 ACTION 键（模型部件 `TransmitLever`，控件 `transmit`）负责建立或加入频道、开始行动、发报、提交猜测和回到房间，键盘快捷键是 Ctrl/Cmd+Enter。条件不满足时按键禁用。回合简报显示期间，ACTION 只负责翻到工作页，不提交任何内容。

**数字键盘。** 实体键 1–4 和 ← 对应键盘的 1–4 和 Backspace。按下数字填入当前位并移到下一位；三位密码不能重复，重复时发出错误音并提示。← 清除当前位，当前位为空时退回上一位。点击屏幕上的某一行可以直接选中那一位。玩法手册打开时，这组键改为翻页：1–4 跳到对应页，← 回上一页。

**线索用系统输入法输入。** 三条线索、代号和频道编号是投影到 CRT 上的原生 `<input>`。输入框保持逻辑字号，整体用 `transform: scale()` 缩放到屏幕上的位置，所以候选词、选区和光标与画面对齐，中文输入法正常工作。线索行内按 Enter 跳到下一行；输入法组字期间的按键不触发任何快捷键。线索最长 80 字，代号最长 20 字，频道编号只接受 4 位字母或数字。

**背对的一面不接收输入。** 游戏页上，正面与背面的控件互斥：`paint()` 只保留当前朝向一侧的目标，`actions.ts` 的 `reachable()` 不让背对的控件起作用，键盘快捷键在机器背对时也不生效（`facingRear()`）。`/preview` 可以自由旋转，两面的目标同时存在。

**断电和脱机时的范围。** 没有供电时，正面只剩电源开关和软盘可以操作；终端脱机时，主屏上只保留「接回网线」。细则见[背面联动](rear-linkage.md)。

**减少动态效果。** 系统开启「减少动态效果」后，本文所有机械动作都直接到达终点：翻面、开关、软盘、名牌、翻牌、走纸和撕纸不再有过程，状态、文字反馈和权限检查保持不变。

**按键行程。** 数字键、ACTION 和复制键被触发时做一次 360 ms 的按下回弹（`parts/keys.ts` 的 `pulse()`），行程分别为 0.07、0.12 和 0.035。

## 电源开关

机身顶部的拨杆开关（`PowerSwitch`，控件 `power-toggle`）。点击或按 Enter/Space 拨动，拨杆整体摆动 32 度（取自模型的 `throw_degrees`），六角螺母、螺纹衬套和铭牌不动。

`powerOn` 只记录开关的位置，机器是否有电由 `consoleHardware()` 结合供电推导。关机后：

- 显像管和词窗按各自的方式熄灭，读数变暗，指示灯熄灭，指针归位；
- 正面的输入和提交停止，已打开的密报记录收起，背景音乐暂停；
- 连接、房间席位、写了一半的线索和猜测都保留；对局的倒计时由服务器掌握，不会因为本机关机而暂停。

电源开关只能在正面操作。失电后开关留在原位，恢复供电不会替玩家开机。

## 把手与翻面

源码：`view.ts`（手势与取景）、`Controls.tsx`（`useHandleGrip`）、`parts/viewpoint.ts`（`beginHandle`、`pullHandle`、`turnTo`）。

**游戏页 `/`** 固定正面平视，没有自由旋转。`gameFraming()` 按窗口尺寸取景：上方留出导航，下方留出翻面提示，两侧把手和顶部开关始终在画面内。

**翻到背面。** 按住任意一侧把手向机身内侧拖动，机器跟手转动。`handlePull()` 把拖动距离换算为进度：分母是舞台宽度的 28%（不小于 160 px），上限 0.65。松手时进度达到 `handleCommit`（0.23）就翻到背面，否则回到正面。向外拖和单纯点击不会翻面。键盘聚焦把手后按 Enter 直接翻面。按 Escape 取消正在进行的拖动。

**回到正面。** 背面四个把手连接座都是返回按钮，点击即可。

翻面时机器绕机身中心转 180 度，转动方向取决于拖的是哪一侧把手；过程中抬起 0.32 并前移 1.3，避开桌面。翻面会合上电池仓盖并清除输入焦点，线索和猜测保留。背面朝前时对局照常更新，机身外的状态条显示当前回合。上一次翻面尚未结束时，新的把手拖动不会开始。

**预览页 `/preview`。** 在空白处或机身上按住左键拖动，或在任意位置按住中键拖动，可以旋转机器：水平方向不限，俯仰限制在 ±1.25 弧度。滚轮缩放，范围 0.65–2.4 倍（`inspectionZoom()`）；指针在旋钮上时滚轮仍然调旋钮。右下角「重置视角」回到初始位置。把手翻面与游戏页相同。

## 密钥软盘

源码：`model.ts`（软盘状态）、`mechanics.ts`（位姿）、`useDiskPull.ts`（手势）。

**职责。** 加密者本轮的三位密码存在软盘里。盘读完之前，主屏不显示密码和对应的密词；盘一离开读头，密码立刻隐藏。这是「只有加密者本人能看到密码」的实体化：别人路过屏幕时，弹出软盘即可遮住。

**一张盘属于一个席位的一个回合。** `keyDiskIdentity()` 由房间、玩家、队伍、回合和密码组成，只有当前回合的加密者、且密码是三个 1–4 之间互不相同的数字时才有值。回合或角色一变，旧盘立即作废。翻译、重绘和阶段更新不会重新送盘。

**送达与插入。** 终端在线且模型就绪后开始送盘，各阶段时长见 `keyDiskDurations`：

| 阶段 | 时长 | 动作 |
| --- | --- | --- |
| `arriving` | 1050 | 软盘从一侧滑入（前 430 ms），亮出标签，再放平对准导轨（650–1050 ms） |
| `inserting` | 1195 | 第一推到与面板齐平（最长 620 ms），停 160 ms 让指尖换到中央凹槽，再克服卡锁阻力（190 ms）、过锁（130 ms）、落座（95 ms） |
| `reading` | 420 | 读头读取密钥 |
| `ready` | — | 密码可见 |

软盘在导轨内始终平放，只沿面板法线方向移动。行程的几个位置：露出待取 0.38（`diskEjectedTravel`），尾端与面板齐平 −0.77（`diskTailTravel`），落座 −0.93（`diskSeatTravel`）。过锁时比落座位置多压入 0.012 再回弹。插入过程中软盘从不后退。

**弹出。** 点击软盘或驱动器上的弹出键（`disk-eject`）。弹出键先被按下（170 ms，键帽行程 0.058），卡锁释放（80 ms），弹簧把软盘推到露出位置（370 ms，临界阻尼，没有回跳），共 620 ms。密码在开始弹出时就隐藏。再次点击露出的软盘即插回。

**用手拖。** 按住软盘沿抽出方向拖动。拖动量 0 表示落座，1 表示弹出位置，2 表示完全取出；屏幕上每一格的像素距离由 `parts/diskDrive.ts` 的 `pullAxis()` 按当前相机投影算出，限制在 48–90 px。

- 移动超过 6 px 才算拖动，之前仍是点击；
- 一开始拖动，读头就撤销读取，即使随后取消；
- 松手时拖动量不小于 1.5 则取出，不小于 0.5 则停在弹出位置，否则落座。归位用时 220 ms；
- 落座后要重新读盘 420 ms 才显示密码；
- 拖过 1.35 之后软盘逐渐抬起并倾斜，表示前缘已离开导轨；
- Escape、窗口失焦、页面转入后台或指针被系统取消时，软盘回到拖动前的位置；
- 取出的软盘点击后先对准盘槽（320 ms）再插入。

**供电。** 只有读头需要电。断电时正在读或已读完的盘停在读取状态并暂停计时，插拔和弹簧弹出仍然可用；复电后从暂停处继续读，不会在此期间露出密码。

**标签。** 每张盘的标签上有一行手写字，从 `diskInscriptions` 的十个短语里按盘的身份取一个，字迹的倾斜、位置和墨色由同一个种子决定，重绘和重新插入后保持不变。

## 名牌卡

源码：`rosterMotion.ts`、`parts/roster.ts`。

正面左侧的名牌架有八个席位，每个席位是一张独立建模的卡片（`RosterCard_A0`–`RosterCard_B3`），上面印着代号、席位号、真人或 AI、房主和「你」的标记，以及对局中的公开进度。名牌架只用于显示，没有点击目标；入队、换队和添加 AI 在主屏上操作。

| 动作 | 时长 | 过程 |
| --- | --- | --- |
| 入席 | 540 | 卡片在槽位上方对齐，退入卡槽，落到固定挡片后面 |
| 离席 | 420 | 卡片先抬起 0.045 脱离挡片，再前移 0.16 让出卡架，然后向上取走 |

`rosterPose()` 把一次动作分成三段：抬起占前 28%，前移占其后 28%，取走占余下 44%；卡片只在最后 12% 淡出。上移总行程取自模型里卡片的 `travel`，缺省 0.58。动作从中途改向时，用时按剩余距离缩短，但不少于全程的三成。

- **换人。** 同一席位换了玩家时，旧卡完全离开视线后才换上新的印刷内容，再插入新卡；两位玩家代号相同也照此处理，因为比较的是玩家 id。
- **同一个人。** 进度或代号变化只更新卡面，不重播插入动作。
- **连续变化。** 只保留最新的一位，不排队播放过期的卡片。
- **空席。** 卡槽底板（`rosterWell{队}{席位}` 表面）印着入队说明，插着卡片时被遮住。

两块队牌（`ThemePanel_A`、`ThemePanel_B`）用同一套动作，行程 0.5：主题或己方队伍变化时，队牌抬出、换色、再落座。

席位显示的在线状态只来自服务器下发的 `disconnected`，不从别的信号推断；对局进度只在代号唯一时才归到某张名牌上。

## 计分翻牌

源码：`scoreFlagMotion.ts`、`scoreRegister.json`、`parts/scoreRegister.ts`。

计分板是四组双联窗口，共八片双稳态翻牌，命名为 `{队}_{intercept|failure}_{0|1}`。每片翻牌正面是深色，背面是暖象牙色珐琅：截获一面印墨色计数，失误一面印朱红叉号。`paintFaces.ts` 按比分算出哪几片该翻开，`parts/scoreRegister.ts` 转动对应的 `ScoreFlag_*` 轴。版面尺寸和材质颜色写在 `scoreRegister.json` 里，建模脚本与运行时共用。

一次翻转的时序：

1. 收到脉冲后等待 22 ms 才释放；同一刻有多片要翻时，每片再依次错开 22 ms；
2. 170 ms 内转过 180 度，由弹簧加速，带着速度撞上挡块；
3. 撞击时发出一声干脆的咔嗒，随后在 64 ms 内向原来的方向回弹一次，幅度不超过 1.2 度。

翻转途中比分又变，翻牌从当前角度转向新目标，用时按剩余角度缩短。尚未释放就被取消的脉冲既不动也不响。

双稳态的含义：

- 载入或恢复对局时，翻牌直接处于正确位置，没有动作也没有声音；
- 断电期间翻牌保持最后的位置，其间比分的变化在复电后补上；
- 背面的灯光自检不会转动翻牌。

## 纸带与密报记录

源码：`mechanics.ts`（走纸）、`tearing.ts`（撕纸）、`ArchiveSheet.tsx`（阅读页）、`model.ts`（`archiveRows`）。

打印机出纸口垂着一小段印有「下拉阅读」的纸头，它是查看公开记录的唯一入口。点击纸头，或按住它向下拖过 16 px，即可打开。打开和走纸需要供电。

**记录的内容。** `archiveRows()` 只收已经公开的回合：当前回合之前的全部回合，以及本轮结算或终局时已经揭晓密码的当前回合。公开的答案只取自服务器下发的历史记录，从不用本机的私密状态（`secretDigits`）拼凑。纸带上的印刷和阅读页用同一份数据。

**走纸。** 纸头静止长度 0.36。拉出时纸长为 `0.98 + 0.38 × 已公开的回合数`，回合数最多计 16，即 0.98–7.06，用时 420 ms（`paperFeedDuration`）。纸长在开始走纸时定下，阅读或撕纸期间到来的新记录只影响下一张。墨迹随纸移动，字的物理尺寸不随纸长变化；压纸辊按实际走纸长度转动，不会倒转。

**阅读页。** 走纸开始的同时，居中的阅读页从视口下方升起，用时与走纸相同。它是一个模态 `<dialog>`，内容依次是：

- 抬头和频道编号；
- 「按编号归档」：两队各自揭晓过的线索，列在它们对应的编号 1–4 之下，对方在前；
- 按时间顺序的回合记录，最早的在上：三条线索、双方提交的次序、公开密码、截获与解码的成败，以及超时未提交的标注；
- 页脚。

整张纸按内容的自然高度排版，在视口内整体滚动。阅读期间，机器上的那张纸保持拉出并连在出纸口上。

阅读页目前没有笔记栏。`notebook.ts` 保留了本地笔记的存储键和解析规则（按房间和玩家分开，单条长度有上限），界面上没有使用。

**收起与撕纸。** 按 Escape、点「收起记录」或点纸外的背景，阅读页向下退出，同时机器上的纸被撕下，两者同为 800 ms（`paperTearDuration`）：前 280 ms 撕断（`paperCutDuration`），后 520 ms 被手带走并淡出。走纸途中关闭，撕下的是当时已经走出的长度。

撕纸是一次基于位置的薄片模拟，不是预先编排的动画：

- 纸是 65 × 41 个质点的网格，每个撕纸齿对应两列，行向齿线加密；模拟每秒 480 步；
- 面内约束让纸不可伸长；跨 1、2、4 格的三点弯曲约束（横向另有 8 格和 16 格）让它保持平整。弯到半径 0.10 以内，纸会留下弯曲的定形；折到半径 0.012 以内成为不回弹的折痕。空气阻尼很大，松开后没有弹簧式的余振；
- 每一列在齿线上由一根纤维拉住，纤维强度成小束地起伏；
- 一只按运动学驱动的手在右侧、齿线下方不远处捏住一块圆角区域：先沿弧线把纸摆向观察者，让纸弯过齿线（0–90 ms），再向下、向左、向外撕（100–270 ms），最后把纸带走；
- 断在哪里不由脚本决定。纤维的载荷只计齿线方向的剪切，加上四分之一的顺纸张力；纸弯过齿线产生的法向压力不计。载荷超出纸悬垂时的静载、且超过该纤维的强度时，它才断开。于是裂口从捏住的一角开始，在强的纤维束前停顿，再向另一侧推进；
- 到 270 ms 还没断的纤维被强制断开，保证在时限内撕完；
- 同一次关闭每次都撕出同样的结果。

测试覆盖的约束：前 60 ms 内没有纤维断开；各种长度的纸（含走了一半的）都在 270 ms 之前自行撕断；撕下的纸像一张硬纸片那样弯过齿线，不卷也不垂。

**齿线以上的纸头。** 齿线和压纸辊之间那一段（`receiptHeadPath()`）在运行时按模型里压纸辊和出纸口的位置生成：纸从辊后的出纸口出来，绕过辊的上方和前方，再落到撕纸齿后面，所以看得见纸是从辊上出来的。这一段与纸带共用印刷贴图，贴图比最长的纸多留 0.7 的长度（`paperHeadReserve`），上面印着下一张纸的开头，走纸和补纸时印刷连续地从辊上出来。

**补纸。** 旧纸带走后，新纸头从出纸口走出，520 ms 内回到静止长度。补纸期间再次点击纸带，会等新纸头到位后再走纸，不会把撕下的纸接回去。

**断电。** 走纸和补纸靠电机，断电即停，复电后继续；用手撕纸不需要电，断电时可以撕完。

阅读页关闭后，键盘焦点回到纸头；手机布局下回到「密报记录」按钮。

## 示波器旋钮与 SIGNAL 接收机

这一节只讲操作。各个旋钮改变了什么画面见[显示器件](displays.md)。

示波器的四个旋钮（FREQ、WAVE、TIME/DIV、X-Y）和 SIGNAL 接收机的两个旋钮（调谐、增益）操作方式相同，都有止挡，不会转过头：

| 输入 | 效果 |
| --- | --- |
| 拖动 | 向右或向上为增大，每 220 px 走完全程；按住 Shift 为 1400 px |
| 滚轮 | 连续转动，单次事件不超过全程的 8%；按住 Shift 为十分之一 |
| 点击 | 前进一格 |
| 方向键 | 右、上前进一格，左、下后退一格；按住 Shift 为十分之一格 |
| Home / End | 转到两端的止挡 |

一格是全程的 2.5%。FREQ 装在游标减速机构后面：拖动和滚轮的灵敏度为其他旋钮的 0.45 倍，一格是相邻两条刻线间距的四分之一，所以用按键一定能落在每一条校准刻线上。旋钮实际改变了数值才发出转动声。拖动之后松手不会再被当成一次点击。

这些旋钮需要供电，并且只能在正面操作。它们是本机的仪器，不发送任何游戏消息，也不读取对局进度、私密线索或网络状况。

**SIGNAL 接收机。** 调谐范围 0–40，增益 0–4。两个旋钮之间的小拨杆（`SignalSweep`，控件 `receiver-sweep`）选择 AUTO 或 MAN：

- AUTO：指针自行摆动，旋钮停在手动设定的位置不动；
- MAN：指针跟随当前的调谐与增益；
- 转动调谐旋钮会切到 MAN；增益在两种模式下都可以调。

SIGNAL 的信号来自背面的 AUX 接口，拔掉后指针回落，见[背面联动](rear-linkage.md)。

## 词窗、手册键与房间码

**词窗。** 点击任意一个词窗（控件 `words`）遮住或重新显示本队的四个密词，用于身边有人时遮挡。终端脱机或尚未开局时不可用。

**ORIGINAL GAME 键。** 左上角的实体键（模型部件 `ManualKey`，控件 `about`）打开原版桌游的介绍页，列出官方网站、BGG 和购买页三个外部链接，并有一个进入玩法手册的按钮。再按一次返回。

**玩法手册。** 主屏右上角的「玩法」按钮（控件 `manual`）打开四页手册，打开时停在与当前阶段对应的那一页。翻页可以用屏幕上的上一步、下一步和页码点，键盘的左右方向键和 1–4，或者实体数字键。最后一页的按钮是「完成」。Escape 关闭手册或介绍页，焦点回到打开它的控件。手册打开期间，`ManualKey` 键帽保持按下 0.035。

**房间码复制键。** 辉光管上方的 COPY 键（模型部件 `ChannelCopy`，控件 `copy-code`）把四位频道编号写入剪贴板，主屏提示已复制；剪贴板不可用时改为直接显示编号。尚未进入房间或终端脱机时禁用。

## 手机布局

源码：`MobileConsole.tsx`。

窗口宽度不超过 850 px 时，游戏页隐藏 3D 舞台，改用一个原生的便携终端界面；没有尺寸的舞台不渲染任何画面。`/preview` 和开发用的细节视图不切换。两种布局共用同一份草稿、校验和动作（`act()`），所以中途改变窗口宽度不会丢失输入。

保留的内容：

- 建立或加入频道、组队、添加和移除 AI、开始行动；
- 本队密词及其遮挡；
- 密钥软盘：向上拖出、弹出键和读盘状态，密码在读完后显示；
- 三条线索的输入，每条旁边标出对应的编号与密词；
- 猜测：每条公开线索一行，配 1–4 和退格键；
- 旁观时行动方三个槽位的实时进度；
- 本轮回执、终局、比分、倒计时与超时提示；
- 密报记录、玩法手册和原版介绍；
- 音效与音乐开关、电池电量、脱机页面，以及机身外状态条里的恢复按钮；
- 固定在底部的 ACTION。

省去的内容：

- 回合简报页。手机上的 ACTION 始终直接提交；
- 机器的背面。接线和电池无法在手机上拆装，需要恢复时用状态条里的按钮；
- 示波器、SIGNAL 接收机、名牌架、计分翻牌和纸带的实体动作；
- 画质选择。

轮到自己行动时，操作区会滚动到可见位置。

## 没有 3D 图形时

WebGL 无法启动、模型载入失败或图形上下文丢失时，页面切换到文字回退（`station-fallback`）：画布隐藏，原本投影在模型上的控件改为按顺序排列的普通按钮和输入框，并显示一段文字记录，内容包括当前状态、本队密词、公开线索、回合与加密者、比分、两队名册和公开记录。页面同时说明原因并提供「重新载入」。此时打开密报记录直接显示阅读页，不等待走纸。

同一段文字记录在正常情况下也存在，只对读屏软件可见。
