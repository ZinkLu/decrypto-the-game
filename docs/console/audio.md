# 声音

终端有两路声音：音效和背景音乐。两路各有开关，互不影响，共用一个音频输出。所有文件都由本站提供，运行时不访问外部主机。

- 素材来源与许可：[`web/public/audio/CREDITS.md`](../../web/public/audio/CREDITS.md)
- 文件怎样制作：[`assets/audio/README.md`](../../assets/audio/README.md)

## 代码在哪里

| 文件 | 职责 |
| --- | --- |
| `web/src/console/sound.ts` | `ConsoleAudio`：音频输出、音效播放；`gameSound`：对局变化对应哪个提示音 |
| `web/src/console/soundBank.ts` | 音效在音效库文件里的位置、音量和最短间隔。由 `assets/audio/build_bank.py` 生成，不要手工修改 |
| `web/src/console/crtSound.ts` | `CrtSoundMotion`：根据主显像管的电气状态决定开关机声音 |
| `web/src/console/music.ts` | `ConsoleMusic`：背景音乐的选曲、淡入淡出、暂停和续播；音乐偏好的读写 |
| `web/src/console/Console.tsx` | 把操作、对局状态和硬件状态接到以上各类 |

## 什么时候出声

浏览器要求用户操作之后才能播放声音。页面载入时只下载音效库，不创建 `AudioContext`。第一次指针按下或按键时才创建并解锁输出，音效关闭时也一样，这样音乐可以单独起播。服务器推来的对局变化不会解锁声音。

页面切到后台时两路声音全部停止。声音文件下载或解码失败时保持安静，不影响任何游戏操作；音乐载入失败时设置里出现「重试音乐」。

## 音效

音效库是一个文件：`/audio/console-foley-v3.wav`（单声道，24 kHz，16 位），里面有 24 种音效、31 个片段。`soundBank.ts` 记录每个片段的起点和时长。

### 机械动作

| 音效 | 触发 |
| --- | --- |
| `key` | 数字键、手册键、复制房间码、翻页、跳过简报、离开房间、弹出软盘、对讲的 TALK 键（切换模式下按一次，按住模式下按下时）；行动者的倒计时最后 5 秒每秒一声 |
| `switch` | AUTO/MAN 拨杆、背面 MUSIC 和 SFX 滑钮、对讲旋钮每转一挡 |
| `knob` | 示波器和接收机的旋钮每转过一格 |
| `latch` | 电池仓开合、取放电池、拔插线缆（整机供电没有因此改变时） |
| `power-on`、`power-off` | 整机得电、失电：拨动电源开关，或拔插线缆、取放电池导致供电改变 |
| `handle` | 拉把手翻转机器 |
| `disk-in`、`disk-seat`、`disk-out` | 软盘推入时的摩擦、到位时的落座、弹出。落座和弹出跟随动画里的撞击时刻 |
| `paper-motor` | 纸带走纸。辊轴转动期间循环播放一段录音，起止有 25–30 ms 的渐变 |
| `paper-feed` | 简化的走纸声，用于手机布局、减少动态效果和 3D 不可用时 |
| `paper-tear` | 撕下纸带，在纤维开始断裂时响起 |
| `score` | 计分翻牌撞到止挡 |
| `test` | 背面灯光自检 |

按键、拨动和旋钮各有几段不同的录音，轮流播放。每种音效有最短间隔，同时最多 12 个声音。请求发出后超过 300 ms 才准备好的音效会被丢弃（灯光自检为 1500 ms），避免延迟的声音与画面脱节。

### 扬声器提示

扬声器提示是窄带的键控载波，不是旋律。`gameSound` 只对新发生的对局变化出声；刚载入的快照、断线恢复和换房间都保持安静。

| 音效 | 触发 |
| --- | --- |
| `transmit` | 按下 ACTION 发出线索或猜测 |
| `turn` | 轮到自己行动：加密阶段的加密者；两队同时猜时，解码的队友和第 3 回合起拦截的对方队员一起响；倒计时剩 15 秒时再响一次 |
| `receive` | 回合揭晓，一回合一次；平局或旁观时的对局结束 |
| `success`、`error` | 对局结束时己方获胜、落败。音乐开启并已解锁时改由结局乐句代替 |
| `error` | 服务器拒绝了操作；猜测里选了重复的数字 |

终端脱机（拔掉网线或失电）期间不播放对局提示，恢复后也不补播。

### 显像管

开关机的电气声有四段：`crt-degauss`（消磁线圈）、`crt-warmup`（升温）、`crt-collapse`（光栅塌缩）、`crt-discharge`（余电放出）。`CrtSoundMotion` 只观察主显像管，其余五支管不重复出声。

- 冷开机时消磁线圈通电；热机重启时线圈的热敏电阻还热，消磁声按余温减弱或省去；切换主题只重开光栅，不消磁。
- 升温声在电源轨建立后响起，画面稳定时结束；塌缩声在光栅收成一条线时响起；放电声跟随最后的亮点。
- 开机途中又关机（或反过来）时，正在播放的电气声立即淡出，开关本身的机械声不受影响。
- 页面刚载入、普通的对局更新和手机布局不产生开关机声音。

## 背景音乐

四段 MP3 在 `web/public/audio/music/`，文件地址写在 `music.ts` 的 `musicFiles` 里。同目录的 `manifest.json` 是制作记录（来源校验值、剪辑点、时长、响度），运行时不读取，由测试核对它与文件一致。

| 曲目 | 文件 | 播放时机 | 方式 |
| --- | --- | --- | --- |
| `lobby` | `lobby-v1.mp3` | 首页和房间 | 循环 |
| `game` | `game-v1.mp3` | 加密、同时猜、回合揭晓 | 循环，跨阶段、跨回合不间断 |
| `win` | `win-v1.mp3` | 对局结束，己方获胜 | 一次 |
| `loss` | `loss-v1.mp3` | 对局结束，己方落败 | 一次 |

- 换场景时两段循环交叉淡化 0.9 秒。打开设置、手册和纸带不会打断音乐。
- 对局结束时循环淡出。知道本机所在队伍、且有明确胜负时播放结局乐句，之后保持安静；平局和旁观只淡出。回到房间后恢复 `lobby`。
- 结局乐句只在新发生的结束时播放一次。断线恢复和重复收到的结果不会重播；2.5 秒内没能载入的结局乐句直接放弃。
- 循环由 `AudioBufferSourceNode` 自身完成，没有用定时器重启。只保留当前一首的解码数据。
- `transmit`、`receive`、`turn`、`success`、`error`、`crt-degauss` 响起时，音乐音量压低到约三分之一，1 秒左右恢复。按键和旋钮不压低音乐。

## 开关、供电和减少动态效果

| 条件 | 音效 | 音乐 |
| --- | --- | --- |
| 背面 SFX 滑钮关闭 | 全部立即停止，包括走纸声；正在下载、解码的音效作废 | 不受影响 |
| 背面 MUSIC 滑钮关闭 | 不受影响 | 立即停止 |
| 整机失电 | 对局提示、走纸、软盘、撕纸和翻牌的声音停止；翻转机器、电池仓、拔插线缆和背面 MUSIC 滑钮仍有声音；显像管放电声照常 | 0.65 秒淡出，恢复供电后从原位置续播 |
| 手机布局（窗口宽度不超过 850 px） | 只有按钮直接触发的声音；没有软盘落座、翻牌、走纸循环和显像管的声音 | 不受影响 |
| 页面在后台 | 全部停止 | 停止，回到前台后从原位置续播 |
| 减少动态效果 | 开关机各只用一段短促的声音；走纸用 `paper-feed` | 不受影响 |

被静音、失电或切到后台打断的结局乐句不会补播。

背面两个滑钮和设置面板里的开关是同一个状态，手机布局也有这两个开关。设置面板另有音乐音量滑块。两路默认开启，音乐音量默认 60%。

音乐的开关和音量保存在 `localStorage` 的 `decrypto-music`，键名沿用历史名称。音效开关不保存，每次打开页面都是开启。
