# 背面联动

机器的背面是它的连接与供电面：三个接口、一个电池仓、两个声音开关和一个灯光自检键。玩家在这里改变设备的条件，正面的屏幕、指示灯和仪表随之响应。

默认接线完整，开机即可使用。玩一整局不碰背面，流程不会多出任何一步；探索背面始终是可选的。

翻面的操作见[机械与交互](mechanics.md)，屏幕与指示灯的画面见[显示器件](displays.md)，声音见[声音](audio.md)。

## 三条关系

| 背面部件 | 职责 | 正面的联动 | 恢复 |
| --- | --- | --- | --- |
| DC 电源 + 四节电池 | 整机供电 | 屏幕、指示灯、SIGNAL、示波器、读盘和电动走纸 | 有电源且总开关在 ON 时恢复 |
| LINK / RJ45 | 终端通信 | NETWORK 灯、主屏通信状态、游戏指令的提交 | 插回后直接呈现当前对局 |
| AUX / SERIAL | 外接接收机的信号遥测 | SIGNAL 指针 | 插回后回到当前调谐与增益对应的读数 |

串口承载的是一台虚构外接接收机的遥测，属于这台设备的设定；项目没有真实的外设或串口通信。

两个部件不受接口影响：

- **示波器**用的是机身正面 INPUT 与 CAL OUT 之间的本地校准回路，只需要整机有电。拔掉网线或 AUX 都不会让波形消失，LOCK 灯只表示振荡器的锁定程度。
- **软盘**是密钥的载体。能否读盘取决于供电、盘的位置和本轮的权限，与 AUX 无关；断网不会把盘弹出，断电也不会。

## 统一的硬件状态

所有表现都从同一个推导结果取值，即 `model.ts` 的 `consoleHardware()`：

```text
supply        = DC 已连接 ? external : 四节电池齐全 ? battery : none
powered       = 总开关 ON 且 supply != none
linked        = RJ45 已连接
online        = powered 且 linked 且 真实连接可用 且 不在恢复席位的过程中
auxAvailable  = powered 且 AUX 已连接
```

`powerOn` 只记录总开关的位置，`unpluggedCables` 和 `removedBatteries` 用位记录每个插头和每节电池。屏幕、仪表、读盘、音乐、走纸和无障碍文字都使用同一个 `powered`；游戏指令的提交和键盘快捷键都使用同一个 `online`，不会出现画面关了而快捷键还能提交的情况。

状态文字（`hardwareMessage()`）按以下优先级只报告最靠前的一条：

1. 无供电：「终端无供电 · 接回 DC 或装齐四节电池」
2. 总开关关闭：「终端电源已关闭 · 输入已保留」
3. 网线拔出：「网线已拔出 · 终端脱机 · 对局仍在进行」
4. 接线完好但连接尚未恢复：「接线已连接 · 正在恢复通信」
5. AUX 拔出：「AUX 已断开 · SIGNAL 无外部输入」
6. 一切正常：「电池供电 · 终端运行正常」或「外部供电 · 终端运行正常」

## 供电

供电的优先级是外部 DC、完整的电池组、无供电。四节电池作为一组，缺任何一节都不能接管；打开仓盖本身不影响供电。

| 条件 | 结果 |
| --- | --- |
| DC 已连接 | 外部供电，取出电池不影响机器 |
| DC 已拔出，四节电池齐全 | 电池供电，设备照常使用 |
| DC 已拔出，任一电池缺失 | 整机失电 |
| 总开关 OFF | 终端关闭，接回电源也不会自行开机 |

**电池接管。** 拔掉 DC 而电池齐全时，机器继续运行，屏幕不变暗也不重启。主 CRT 右上角出现一个电池标记：细线外框和电极，里面四格斜向的电量格，三格亮、一格暗，旁边是 `75%`。这是固定的演示值，不模拟电量消耗。接回 DC 或失电后标记消失。手机布局和文字回退显示同样的电量。

**失电。** 随后取出任一节电池，整机失电：显像管和点阵熄灭，指示灯熄灭，指针归位，音乐在 0.65 秒内淡出。机械计分翻牌、纸带和软盘留在原来的物理位置。正在进行的读盘暂停；电动走纸和补纸停止，已经开始的手撕纸可以撕完，弹簧弹盘和手动插拔软盘仍然可用。

**恢复。** 接回任一可用电源后，若总开关在 ON，机器正常启动并呈现当前状态；若在 OFF，状态文字转为「终端电源已关闭」。恢复供电不会改动网线、AUX 和总开关。

**电池仓。** 点击电池仓开合仓盖。仓盖打开后点击某一节电池将它取出，取出的电池停在仓位下方，再点一次装回。仓盖是独立的铰接部件，电池不随它移动。翻回正面时仓盖自动合上。

没有实现电量消耗、充电、随机接触不良或维护任务。

## 网线

拔出网线表示这台终端转入本地状态。浏览器与服务器之间真实的连接不会关闭：底层状态继续接收，席位保留，对局和其他玩家不受影响。

### 拔出之后

- 背面 RJ45 的 LINK 与 ACT 灯熄灭，正面的 NETWORK 灯熄灭。
- 主屏换成「已断开连接」页，并说明是网线被拔出还是正在重新连接。四个词窗显示「离线」，房间码显示 `0000`，复制键停用。手机布局和文字回退一致。
- 这台终端不再发出任何游戏指令：建立、加入、换队、开始、提交和进度同步都停止，键盘快捷键同样无效。
- 已经写下的线索和选好的编号保留，不会自动提交。
- 示波器、SIGNAL 和声音设置照常可用。公开的密报记录仍可查阅。
- 实时的阶段、计时和计分停止呈现。机身外的状态条显示当前回合，并注明对局仍在进行。

### 保留与撤销

脱机期间画面停在脱机前的状态（`terminalView()`），但过期的秘密立刻撤销：

- 席位变了，或本队的密词变了，词窗内容清空；
- 回合或角色变了，本轮密钥对不上，私密密码和对应的密词清空，旧软盘作废。

后台持续接收状态，不代表旧的秘密可以继续显示。

### 插回

- 真实连接可用、最新状态有效时，NETWORK 灯才亮起并保持。真实网络仍不可用时，状态文字是「接线已连接 · 正在恢复通信」，主屏显示「正在尝试重新连接…」，把物理接线和真实连接区分开。
- 画面直接回到当前回合和当前角色，不按顺序回放错过的提交、提示音或打印动作。
- 脱机期间写的内容不会自动提交。原来的回合还能操作时草稿仍在；回合已经过去时，草稿作为「旧草稿 · 第 N 回合」留在状态条里供查看，不填入新回合。
- 已经发出而尚未确认的提交以服务器的回执为准。拔线不能撤回指令，也不会触发重发。

## AUX

AUX 是外接接收机的遥测。SIGNAL 表示这条辅助通道的接收强度，与真实网络质量、玩家的思考进度和答案的对错都无关。

接着 AUX 时，AUTO 提供随机起伏的电台活动，MAN 使用当前调谐位置上三个模拟电台的强度。两种模式都以 AUX 已连接为前提。

拔出后，指针在约 0.3 秒内回落到接近零的位置并停住。调谐和增益旋钮保留位置，仍然可以转动，AUTO/MAN 拨杆也留在原位。插回后，指针在约 0.2 秒内回到当前调谐、增益和模式决定的读数，不扫满刻度，也不重置旋钮。

AUX 不接管示波器的输入，也不兼任声音总线：拔掉它不会关闭背景音乐或按键声。

## 灯光自检

LAMP TEST 只检查灯。按下后 1.8 秒内，背面的测试灯、RJ45 两个灯、正面的 NETWORK 灯和示波器的 LOCK 灯一起点亮，结束后回到各自真实的状态。它不改变连接状态，不转动计分翻牌，也不显示「联网成功」。没有供电时不可用。

## 声音开关

背面扬声器下方有 MUSIC 和 SFX 两个独立的滑动开关，默认都在 ON；浏览器要求的首次用户操作之后声音才开始播放。同样的开关在右上角的设置面板和手机布局里也有。

- 音乐的开关和音量保存在本机（`localStorage`）。SFX 开关的位置只在当前页面内有效。
- 失电时音乐暂停，偏好保留，复电后按当前阶段继续。
- 机器本体的动作声（走纸、软盘落座与弹出、翻牌）在失电时不响。显像管断电后的放电声仍然会有，只受 SFX 开关控制。
- 拔插和开关本身有闩锁声；供电状态发生变化时改为开机或关机声。

## 反馈先在背面成立

玩家拔插时看不到正面，所以每次操作同时具备三层反馈：

1. **手上的反馈。** 插头脱离或就位，线缆跟着弯曲（线缆是锚定在机身下方的独立网格，用 `unplugged` 形变目标弯折，不是整体平移），SFX 开启时有接触声。
2. **背面的依据。** 网口灯和测试灯的亮灭，加上机身外状态条里的一句具体结果。
3. **正面的结果。** 翻回去之后，脱机页、归零的指针或断电的机器仍然摆在那里。

机器不会自动翻面，已经发生过的故障动画翻面后不重播。

拔插用点击完成，也可以用键盘聚焦后按 Enter。鼠标悬停或获得焦点时，控件说明后果，例如「拔出网线 · 终端将脱机」「拔出串口线 · SIGNAL 将失去输入」「拔出电源线 · 尝试由电池接管」。操作不需要确认弹窗。

## 恢复入口

会阻止游戏操作的故障都能从当前看得见的界面恢复，不要求玩家翻到背面：

| 故障 | 入口（`hardwareRecovery()`） | 动作 |
| --- | --- | --- |
| 无供电 | 状态条：「接回电源」 | 接回 DC 插头 |
| 总开关关闭 | 状态条：「开启终端电源」 | 拨到 ON |
| 网线拔出 | 状态条和主屏脱机页：「接回网线」 | 接回 RJ45 插头 |

同时有多个故障时，每次只给出优先级最高的一个入口，修复一个原因，不重置其他硬件设置。AUX 不影响游戏操作，没有快捷入口，在背面插回即可。

状态条在机器背面朝前、终端不在线或留有旧草稿时出现。手机布局和文字回退用同一个状态条，所以在没有背面可翻的界面上也能恢复。

## 状态的范围

- 首次进入时接线完整。拔线和取电池只保留在当前页面，刷新后复原；进入另一个房间时，接线、电池和仓盖也复原。总开关的位置不随房间复原。
- 主题、语言和音乐偏好按各自的规则保存，不受背面操作影响。
- 恢复动作只恢复连接与展示，不产生任何游戏指令。
- 减少动态效果时，线缆、指针和画面直接到达目标状态；文字反馈、权限检查和恢复方式保持完整。状态从不只靠声音、颜色或闪烁表达。
