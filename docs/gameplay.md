# 玩法

Encrypto 是两支队伍之间的猜词游戏。每队有四个只有自己看得见的密词，轮流用线索把一组三位密码传给队友，同时提防对手从历次线索里摸出规律。先截获对手两次的一队获胜，先译错自己人两次的一队落败。

规则取材于桌游《Decrypto》，想了解原作可以看[原版规则](https://www.scorpionmasque.com/sites/scorpionmasque.com/files/decrypto_en_rules_20sep2019.pdf)。机器主屏右上角的「玩法」也有一份四页的图解。

想先看一遍实际的过程，这里有一段 [52 秒的视频](media/gameplay.mp4)。

## 开一局

1. 打开页面，在主屏上填好代号，按红色的 **ACTION** 建立频道。
2. 右上角的辉光管亮出四位房间码，按旁边的 **COPY** 复制，发给朋友。朋友选「加入频道」，填代号和房间码。
3. 进入房间的人自动坐到人少的一队，也可以在主屏上换队。每队 2 到 4 人。
4. 人不够时，房主可以给任意一队加 AI 队员。
5. 两队各有至少 2 人后，房主按 **ACTION** 开始。

没有座位的人可以留在房间里旁观。

![房间：左侧名牌架上插着每个人的名牌](media/play-room.jpg)

## 一个回合

两队轮流发报，A 队先开始。每个回合先由发报一队加密，然后两队同时猜，都提交后一起揭晓。回合开始时，主屏用一页简报说明这一回合谁做什么、你现在要做什么。

### 1. 加密

发报一队里轮到的那位是**加密者**。密钥软盘送进驱动器，读完之后，主屏上出现本回合的三位密码，例如 `3 · 1 · 4`，以及它们对应的密词。

加密者按密码的顺序写三条线索：第一条指向 3 号词，第二条指向 1 号词，第三条指向 4 号词。写完按 **ACTION** 发出，三条线索对所有人公开。

![加密：密码只出现在加密者的屏幕上](media/play-encrypt.jpg)

身边有人时，弹出软盘可以立刻遮住密码，点一下词窗可以遮住密词。

### 2. 两队同时猜

线索一公开，两队同时开始猜这三条线索各指向几号词：

- **加密者的队友解码。** 他们看得到自己的四个密词。
- **对手拦截。** 他们看不到发报一队的密词，只能对照此前公开过的线索。前两个回合没有拦截，因为还没有可以参照的记录。

点主屏上的一行，再按机身上的数字键 1–4，三位都填好后按 **ACTION**。

![拦截与解码：选中一行，再按数字键](media/play-guess.jpg)

同队的人共用一次提交：任何一位按下 **ACTION**，服务端收下的第一份有效答案就成为本队答案，不用等所有人的选择一致。主屏的每条线索旁列出队友的代号、当前选的数字，以及正在推敲的格子，方便一起比较；每个人仍操作自己的三位选择，别人的输入不会替你改答案。先交的一队等另一队。

揭晓之前，谁也看不到对方选了什么，只能看到对方交了没有、正在选第几位。加密者只能看着：两队选的数字都在他的屏幕上，软盘读着时还标出对错，但他不能提示或提交猜测。

### 3. 揭晓

两队都交了，或者时间到了，主屏给出本回合的回执：密码是什么，双方各猜了什么，对不对。

| 结果 | 记分 |
| --- | --- |
| 对手的三位与密码完全一致 | 对手记一次**截获** |
| 队友的三位与密码不一致 | 发报一队记一次**失误** |

两项分别计算，同一回合可以都发生。右侧的计分板上，对应的翻牌会翻过来。几秒之后下一个回合开始，换另一队发报。

## 胜负

- 一队截获对手 **2 次**，获胜。
- 一队失误 **2 次**，落败。
- 打满 **16 个回合**仍未分出胜负，则比较「截获次数减失误次数」，高的一队获胜，相同为平局。

终局时双方的四个密词一起公开。任何一位玩家按 **ACTION** 都可以让房间回到大厅，原班人马再来一局。

## 时间

| 步骤 | 时限 |
| --- | --- |
| 写线索 | 90 秒 |
| 拦截、解码 | 60 秒，两队同时开始计时 |

时钟在数字键的左边，最后 15 秒变色，主屏同时给出提醒。时间到了还没有提交，服务器替你交：

- 线索发出已经写下的部分，空着的行记为 `—`；
- 猜测使用本队最后一次上报的真人草稿；三位都选好且各不相同则代交，否则记为放弃，这次拦截或解码算失败。AI 的建议不会覆盖这份草稿。

一队超时不影响另一队：另一队已经交了的，照常结算。

## 查看记录

打印机出纸口垂着一小段纸。点它或向下拉，机器把所有已经公开的回合打印出来：每条线索、公开的密码、双方的猜测和成败，并按 1–4 号把每队用过的线索归在一起。推理对手的密词主要靠这张纸。

![纸带：已经公开的全部记录](media/play-archive.jpg)

按 Esc 或点纸外的空白处收起，机器上的那张纸随之撕掉。

## 和 AI 一起玩

AI 队员和真人一样写线索、猜数字。猜测开始时，每位有资格作答的 AI 都会同时开始独立推理，在每条线索旁以自己的代号给出建议数字；每个人的思考、重试、就绪和未完成状态分别显示，互不覆盖。加密者只写线索，不会同时参与本回合的猜测。

同队只要有能作答的真人，所有 AI 就都只提供建议，不会替真人提交，也不会自动填入你的输入；你可以参考后自行选择，照常按 **ACTION** 提交。这种混合队伍仍有 60 秒，服务端收下的第一份有效真人答案作为本队答案。

如果能作答的队员全是 AI，它们仍然同时独立推理，其中按座次排在第一位的 AI 有权自动提交，其余 AI 只给建议，这时这一队有 120 秒。你加密、其他队友全是 AI 时，也按这个方式自动解码。任何一队提交后，这一队尚未完成的 AI 推理会停止；两队各自进行，不互相阻塞。

AI 需要服务器配置模型的密钥，见[构建与运行](getting-started.md#ai-队员)。没有配置或者某位 AI 没能答上来时，那位 AI 的建议显示未完成，其他队友仍能照常作答；需要 AI 自动完成的加密或猜测则使用「线索暂缺」或合法猜测这样的备用答案，主屏上会注明。建议不会用备用数字冒充推理结果。

## 语音

服务器开启了语音时，有两处可以操作：页面顶上的语音栏，和机器底部通风槽旁边的对讲。把对讲旋钮从 OFF 转到 ALL（或者按语音栏的「加入语音」）就接入了；转到 TEAM 等于开「悄悄话」，转回 OFF 退出。第一次接入，浏览器会请求使用麦克风；不允许也能接入，只是只能听。

对讲上的灯：RX 灯随你听到的声音亮起；ALL、TEAM 刻度上的小灯告诉你声音此刻送到哪里；TALK 键上的红灯亮着，说明你的声音正在送出去。

- **平时全桌都听得见。** 大厅里、加密者写线索时、每回合揭晓之后，所有人在一个频道里说话。按「悄悄话」，你的声音只给队友听。
- **猜的时候两队分开讨论。** 加密者发出线索之后，直到这一回合的密码揭晓，每队只听得到自己人。这段时间里加密者不能说话，只能听队友怎么猜。分开和回到全桌时会听到一声电台的「咔」，顶上的文字也会提示几秒。
- **开麦与闭麦。** 用 TALK 键或语音栏：默认点一下开麦、再点一下闭麦；设置里可以改成「按住说话」。数字 1 左边的 ` 键是快捷键。
- **机器断电或拔掉网线时，对讲也停了**，接回就恢复。
- 没有座位的旁观者只听得到全桌，两队分开讨论时暂时听不到声音。

## 这台机器

| 部件 | 用来做什么 |
| --- | --- |
| 主屏 | 当前要做的事；「玩法」打开图解 |
| 四个词窗 | 本队的四个密词，点一下遮住 |
| 名牌架 | 两队的成员，谁在行动 |
| 辉光管与 COPY | 房间码 |
| 计分板 | 两队的截获与失误 |
| 打印机 | 公开记录 |
| 时钟与阶段灯 | 剩余时间，当前在哪一步；两队同时猜时，拦截和解码两盏灯一起亮，哪队交了哪盏就熄 |
| 数字键与 ACTION | 填数字，确认 |
| 软盘驱动器 | 加密者的密码 |
| 示波器与 SIGNAL 表 | 等待的时候可以拧着玩，不影响对局 |
| 对讲：旋钮、TALK 键和三类灯 | 房间里的语音，见上一节 |
| ORIGINAL GAME 键 | 原版桌游的介绍和购买链接 |

**键盘。** 每个控件都可以用 Tab 聚焦。数字键 1–4 和 Backspace 对应机身上的键盘，Ctrl/Cmd+Enter 等于 ACTION，Esc 关闭打开的页面。

**设置。** 页面右上角的「设置」里可以换语言（中文 / English）、主题配色、画质，以及语音的说话方式和音量。它们只影响你自己的页面。

**背面。** 按住任意一侧把手向机身里面拖，机器会翻过来。背面有电源、网线、AUX 接口、电池仓，以及音乐和音效的开关；拔掉它们，正面会有相应的反应。点背面的把手连接座翻回正面。什么都不动也能正常玩。

![背面：供电、接线和声音开关](media/play-rear.jpg)

**手机。** 窄屏上页面换成一个紧凑的终端，功能相同，没有 3D 机身。

## 掉线了怎么办

刷新页面、网络中断或者服务器重启之后，页面会自己连回去，回到原来的座位和原来的回合，写了一半的线索也还在。对局进行中座位一直为你保留。

房间里所有真人都离开满 10 分钟，房间才会关闭。
